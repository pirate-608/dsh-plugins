# Editing workflows

## Project and ingest

1. Confirm the project destination and create or open the project.
2. Import only the user-specified media. Preserve original filenames and locations.
3. Create clear bins for footage, audio, graphics, sequences, and exports when useful.
4. Resolve frame-rate, frame-size, audio-channel, proxy, and color-space mismatches before bulk editing.

## Sequence setup

Prefer a sequence derived from the primary camera clip unless the user specifies delivery settings. Verify frame size, timebase, pixel aspect ratio, audio sample rate, and track layout. Name sequences descriptively and duplicate an existing sequence before structural revisions.

## Timeline edits

- Confirm the active sequence and selected track targets before inserting or overwriting.
- Use ripple trims only when downstream timing should move; use regular trims when timing must remain fixed.
- Check linked audio/video state before moving or deleting clips.
- Review edit points around the playhead after trimming, especially J/L cuts and transitions.
- Use transitions sparingly and verify sufficient handles exist.
- For vertical or square delivery, prefer sequence-specific reframing and inspect important subjects at representative points.

## Titles and graphics

Confirm spelling, language, placement, safe margins, font availability, and duration. Reuse an existing project style when present. Do not invent brand styling when the project supplies a template or graphics package.

## Verification

After a batch of edits, scrub or play representative sections and inspect for gaps, flash frames, unintended track shifts, disabled clips, missing audio, and out-of-frame subjects. Save only after the result matches the requested intent.
